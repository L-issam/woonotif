Politique de Confidentialité - WooNotif

Dernière mise à jour : 24 octobre 2026

Introduction

WooNotif ("nous", "notre", "l'application") respecte votre vie privée. Cette politique de confidentialité explique comment nous collectons, utilisons, stockons et protégeons vos informations lorsque vous utilisez notre application mobile.

Légitimité de l'application

WooNotif a été développée pour répondre à un besoin réel : permettre aux marchands et collaborateurs de suivre les commandes WooCommerce, Shopify ou Wix sans installer de plugins lourds comme Jetpack. Cette application est une solution testée en conditions réelles, créée pour simplifier la gestion des commandes depuis un appareil mobile.

Informations que nous collectons

Important : Un compte WooNotif (e-mail/mot de passe ou Google) est requis. Les clés API boutique et la plupart des données de commandes restent sur votre appareil. Le compte, les notifications push, les abonnements store et (en Pro) commentaires / équipe passent par Firebase (Google) — Auth, Firestore, Cloud Messaging / Cloud Functions.

Compte WooNotif (Firebase Authentication)

  • Adresse e-mail : fournie à la création de compte e-mail, ou via Google Sign-In
  • Mot de passe : si connexion e-mail — traité par Firebase Auth (nous ne le stockons pas en clair)
  • Identifiant utilisateur (UID) : identifiant technique Firebase lié à votre compte
  • Profil Google (si vous choisissez « Continuer avec Google ») : e-mail et, le cas échéant, nom d’affichage transmis par Google pour l’authentification

Finalité : authentification, sécurité du compte, association de vos données cloud (push, prefs, équipe) à votre UID. Réinitialisation du mot de passe : e-mail envoyé via Firebase.

Identifiants boutique (stockage local)

  • URL de boutique (WooCommerce, Shopify ou Wix)
  • Clés / tokens API (Consumer Key/Secret, access token, etc.)

Ces informations sont stockées uniquement sur votre appareil (stockage local de l’application). Elles ne sont pas envoyées vers Firestore pour y être conservées.

Données des commandes

  • Informations de commandes (numéro, date, client, montant, statut) récupérées via l’API de votre boutique
  • Affichage et traitement principalement sur l’appareil ; les payloads de notification push restent minimaux (ex. identifiants de commande / boutique pour le routage)

Données cloud liées au compte (Firebase / Firestore)

  • Tokens de notification push (FCM) et abonnements aux boutiques pour router les webhooks
  • Préférences de notification (ex. heures silencieuses) associées à votre UID
  • En Pro : commentaires synchronisés, métadonnées d’équipe / invitations (sièges collab)

Données techniques & pubs / achats

  • Permissions de l’appareil (caméra pour scanner les QR codes)
  • Identifiants publicitaires / données AdMob si vous n’êtes pas Pro (voir section Publicités)
  • Données d’achat / abonnement Pro via Google Play Billing

Comment nous utilisons vos informations

Utilisation des données

  • ✓ Compte : vous connecter et sécuriser l’accès à l’app
  • ✓ Affichage des commandes : visualiser les commandes de vos boutiques
  • ✓ Notifications : vous alerter des nouvelles commandes (si activé)
  • ✓ API boutique : appeler WooCommerce / Shopify / Wix avec vos clés locales
  • ✓ Équipe (Pro) : invitations et sync commentaires entre membres autorisés
  • ✓ Premium : gérer l’abonnement sans publicités via Play Billing

Ce que nous ne faisons PAS

  • ✗ Nous ne vendons PAS vos données à des tiers
  • ✗ Nous n'envoyons PAS vos clés API boutique (CK/CS, tokens) vers Firebase pour les stocker
  • ✗ Nous n'accédons PAS à votre boutique sans votre autorisation explicite
  • ✗ Nous ne modifions PAS produits, prix ou réglages — l’écriture de statut commande n’existe qu’en Pro avec clé write opt-in

Stockage et sécurité

Stockage local et cloud

Sur l’appareil :

  • Identifiants API boutique et données d’usage locales
  • Session / persistance Auth côté client
  • Suppression locale : désinstallation ou « Effacer les données » de l’app

Sur Firebase / Google Cloud (lié à votre compte) :

  • Compte Auth (e-mail / fournisseur Google, UID)
  • Tokens push, abonnements notifications, préférences liées à l’UID
  • En Pro : commentaires sync et memberships / invitations d’équipe

Pour supprimer aussi le cloud : voir la page Suppression des données.

Sécurité

  • Connexions HTTPS uniquement (obligatoire)
  • Authentification Basic Auth sécurisée
  • Stockage local chiffré par le système d'exploitation
  • Aucune transmission de données sensibles en clair

Permissions de l'application

Caméra

  • Usage : Scanner les QR codes contenant vos clés API WooCommerce
  • Stockage : Aucune image n'est sauvegardée
  • Accès : Uniquement lorsque vous activez le scanner QR

Notifications

  • Usage : Vous alerter des nouvelles commandes
  • Contrôle : Vous pouvez activer/désactiver à tout moment dans les paramètres
  • Données : Aucune donnée personnelle n'est incluse dans les notifications

Internet

  • Usage : Se connecter à votre boutique WooCommerce via l'API REST
  • Sécurité : Connexions HTTPS uniquement

Vos droits

Vous avez le droit de :

  • ✓ Accéder aux informations de votre compte (e-mail affiché dans l’app)
  • ✓ Vous déconnecter à tout moment
  • ✓ Supprimer les données locales (désinstall / effacer données)
  • ✓ Demander la suppression du compte et des données cloud (Auth, Firestore)
  • ✓ Révoquer l'accès à votre boutique (supprimer le store dans l’app)
  • ✓ Désactiver les notifications

Pour exercer ces droits : paramètres de l’app / appareil, page Suppression des données, ou contact ci-dessous.

Cookies et technologies de suivi

L'application n'utilise pas de cookies web. Les communications commandes se font principalement entre votre appareil et votre boutique (WooCommerce, Shopify ou Wix) via HTTPS. Le compte, les push et certaines fonctions Pro passent par Firebase / Google Cloud. AdMob peut utiliser des identifiants publicitaires (utilisateurs non Pro).

Publicités (Google Ads)

Si vous avez activé les publicités dans l'application :

  • Google AdMob peut collecter des données anonymes pour personnaliser les publicités
  • Ces données sont gérées selon la Politique de confidentialité de Google
  • Vous pouvez désactiver la personnalisation des publicités dans les paramètres de votre appareil

Partage avec des tiers

Nous ne vendons vos données à aucun tiers. Des prestataires techniques interviennent pour le service :

  • Google Firebase Authentication : compte e-mail ou Google Sign-In
  • Google Firebase / Cloud : Firestore, FCM, Cloud Functions (push, webhooks, sync Pro / équipe)
  • Google AdMob : publicités (utilisateurs non Pro)
  • Google Play Billing : achats d’abonnement Pro
  • Votre boutique : WooCommerce, Shopify ou Wix via leurs API (données que vous contrôlez)

Conservation des données

Vos données sont conservées :

  • Sur votre appareil : jusqu’à désinstallation ou réinitialisation
  • Compte Firebase Auth : jusqu’à suppression du compte (demande via la page suppression ou contact)
  • Firestore : tokens / abonnements push, prefs liées à l’UID et, en Pro, commentaires sync / memberships — jusqu’à suppression demandée ou désabonnement

Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité. Les modifications seront signalées par :

  • Une notification dans l'application
  • Une mise à jour de la date "Dernière mise à jour"
  • Une nouvelle version de l'application

Conformité légale

Cette application est conforme au :

  • RGPD (Règlement Général sur la Protection des Données) - UE
  • CCPA (California Consumer Privacy Act) - Californie
  • Loi sur la protection des données - Canada
