Demande de Suppression des Données - WooNotif

ℹ️ Où sont vos données ?

WooNotif utilise un compte (e-mail ou Google via Firebase Authentication).

  • Sur l’appareil : clés API boutique, caches, préférences locales
  • Dans le cloud (Firebase) : compte Auth (e-mail / UID), tokens push, abonnements notifications, préférences liées au compte ; en Pro : commentaires sync et memberships / invitations d’équipe

Désinstaller l’app ne suffit pas pour effacer le compte cloud : suivez aussi l’étape 3.

Comment supprimer vos données

1 Données locales — désinstaller l’application

  1. Paramètres Android → Applications → WooNotif
  2. Appuyez sur « Désinstaller »

Résultat : clés API, caches et données locales supprimés de l’appareil.

2 Données locales — effacer sans désinstaller

  1. Paramètres Android → Applications → WooNotif → Stockage
  2. « Effacer les données » / « Réinitialiser »

Résultat : l’app reste installée ; vous devrez vous reconnecter.

3 Compte & données cloud — demande par e-mail

Pour supprimer votre compte Firebase et les documents cloud associés (tokens push, abonnements store, prefs, équipe / invitations, commentaires sync) :

  1. Écrivez à sslaouane@gmail.com
  2. Objet suggéré : WooNotif — Suppression compte et données
  3. Indiquez l’adresse e-mail du compte WooNotif (celle utilisée à la connexion e-mail ou Google)

Délai : nous traitons la demande sous un délai raisonnable (objectif : sous 30 jours), puis confirmons par e-mail.

⚠️ Ce qui est supprimé

Local (étapes 1–2) :

  • URL et clés / tokens API des boutiques
  • Caches commandes et préférences locales

Cloud (étape 3, après traitement) :

  • Compte Firebase Authentication (e-mail / liaison Google)
  • Tokens FCM, abonnements notifications, préférences liées à l’UID
  • Données d’équipe / invitations et commentaires sync (Pro) liés à ce compte

⚠️ Ce qui n’est pas sous notre contrôle exclusif

  • Google AdMob : données pub éventuelles — voir Politique Google et les réglages de votre appareil / compte Google
  • Google Play Billing : historique d’achat géré par Google Play (annulation / gestion dans Play Store)
  • Votre boutique (WooCommerce / Shopify / Wix) : les commandes restent chez votre plateforme e-commerce

✅ Déconnexion seule

Vous pouvez aussi vous déconnecter dans l’app (écran d’ajout de store ou Paramètres) sans supprimer le compte. Les données cloud restent jusqu’à une demande de suppression (étape 3).
