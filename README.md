WooNotif est une application mobile multi-platforme pensée pour les propriétaires de boutiques WooCommerce, Shopify ou Wix qui veulent suivre leurs commandes en temps réel,  ou permettre à leurs collaborateurs de recevoir et voir les nouvelles commande et leurs détails de livraison, le tout sans devoir ouvrir un ordinateur ni installer de plugins lourds comme Jetpack. Recevez des notifications dès qu’une nouvelle commande arrive et gardez une vue claire de l’activité de votre boutique où que vous soyez.
Avec WooNotif, vous pouvez :
- Consulter vos commandes récentes WooCommerce, Shopify ou Wix directement depuis votre smartphone.
- Voir rapidement le client, le montant, le statut, la date de chaque commande et les détails de livraison.
- Actualiser la liste pour suivre en temps réel l’activité de votre boutique.
- Recevoir des notifications (si vous les activez) lorsqu'une nouvelle commande est créée.
WooNotif. Vous gardez ainsi le contrôle complet sur votre boutique : l’application ne peut pas modifier vos produits, vos commandes ou vos réglages.
- Ajouter localement un commentaire sur une commande, ou ajouter le même commentaire directement à plusieurs commandes, et pouvoir exporter le tout sous forme de PDF ou de CSV. Un exemple de commentaire : "livré le.."
Comment ça fonctionne pour une boutique woocommerce ?
1- Vous générez une clé API WooCommerce en lecture seule depuis l’interface d’administration WordPress.
2- Vous saisissez l’URL de votre boutique, la Consumer Key et la Consumer Secret dans l’application WooNotif.
3- WooNotif se connecte à votre boutique via HTTPS et affiche vos commandes.
Chaque type de store à une première configuration à faire au début qui change bien evidemment en fonction de la plateforme, mais ça reste le même principe :
Créer des identifiants en lecture seule pour pouvoir se connecter au store, et l'ajout d'un webhook pour recevoir les nouvelles commandes en temps réel (expliqué dans le site officiel ou directement à https://l-issam.github.io/woonotif)
Aucune installation de plugin supplémentaire n’est nécessaire côté WooCommerce, wix ou shopify .
Respect de la confidentialité :
WooNotif a été conçu pour respecter votre vie privée et celle de vos clients :
- Aucune donnée n’est stockée sur nos serveurs ou n'importe quel serveur externe.
- Les identifiants API (CK/CS) sont stockés uniquement sur votre appareil, dans le stockage local sécurisé.
- Toutes les données affichées (commandes, clients, montants) proviennent directement de votre propre boutique WooCommerce.
- Vous pouvez supprimer toutes les données locales à tout moment en désinstallant l’application ou en réinitialisant ses données dans les réglages Android.
Les publicités intégrées sont gérées par Google AdMob. Certaines données d’utilisation peuvent être utilisées par Google pour personnaliser les annonces, conformément à la politique de confidentialité de Google.
Pour qui ?
WooNotif est idéal si vous :
- Gérez une boutique WooCommerce, Shopify ou Wix et souhaitez être notifié rapidement des nouvelles commandes.
- Travaillez en équipe et voulez donner à vos collaborateurs un accès simple à la liste des commandes, sans accès complet à l’admin de votre store.
- Cherchez un outil léger, sans serveur intermédiaire, centré sur la consultation et la réactivité.
Points clés :
- Suivi des commandes WooCommerce, Shopify et Wix en temps réel.
- Notifications de nouvelles commandes (si activées et webhook configuré).
- Connexion sécurisée via HTTPS et clés API en lecture seule.
- Données stockées uniquement sur votre appareil.
- Aucune donnée envoyée à un serveur tiers en dehors de votre boutique et de Google AdMob pour les annonces.
Évolutions prévues :
WooNotif va continuer d’évoluer pour répondre encore mieux aux besoins des marchands et des équipes logistiques.
- Mode adapté aux livreurs et préparateurs de commandes, notamment pour les boutiques qui fonctionnent en paiement à la livraison (cash on delivery) : suivi rapide des nouvelles commandes, priorisation par zone ou par statut, meilleure visibilité sur les commandes du jour.

## 🛠️ Développement

### Prérequis

- Node.js 18+
- npm ou yarn
- Expo CLI
- EAS CLI (pour les builds)

### Installation

```bash
# Cloner le repository
git clone [votre-repo]
cd woonotifs

# Installer les dépendances
npm install

# Lancer en mode développement
npm start
```

```
woonotifs/
├── app/                    # Routes Expo Router
│   ├── (tabs)/            # Onglets de navigation
```
